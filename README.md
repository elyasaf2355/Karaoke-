# מכוון

אפליקציית ווב שבודקת אם שרים בול, גבוה או נמוך. הכול רץ בדפדפן, בלי שרת, והקול לא יוצא מהמכשיר.

## שלושה מצבים

* **כוונון:** שרים צליל, והאפליקציה מראה כמה הוא רחוק מהצליל הקרוב בסולם.
* **שיר:** האפליקציה מנגנת שיר, ואתם שרים את המנגינה. נבדקים הצליל והאוקטבה, או "בקול שלי" שמתאים את המנגינה לגובה שלכם.
* **קריוקי:** המוזיקה מנגנת במקום אחר (רמקול), והטלפון מקשיב. האפליקציה מזהה את הסולם לבד, כולל שינוי סולם באמצע השיר.

## הרצה

```
npm run serve        # ואז לפתוח http://localhost:8000
```

המיקרופון עובד רק בכתובת https או ב־localhost. לשימוש בטלפון: GitHub Pages.

## מסמכים

* [עיצוב הקוד](docs/ARCHITECTURE.md): מבנה, תלויות, זרימת נתונים, איך מרחיבים.
* [כיוונים ושיפורים](docs/ROADMAP.md): רעיונות, ערך מול מאמץ, וסדר עבודה מומלץ.

## בדיקות

`npm test` (דורש Node 20+, בלי תלויות). הבדיקות מסנתזות שמע (אקורדים עם הרמוניות, בס, תופים, שירה עם ויברטו),
ומריצות עליו את אותו קוד של האפליקציה: FFT, זיהוי גובה צליל, זיהוי ומעקב סולם.
בדיקות "ביקורת" מוכיחות שהבדיקות מסוגלות להיכשל (למשל: בלי סינון שירה, ועם סולם קפוא).
מגבלות ידועות מסומנות כ-`todo` ומופיעות בדוח.
