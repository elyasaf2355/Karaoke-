# בודק זיופים

אפליקציית ווב שמזהה את גובה הצליל של הזמר בזמן אמת ואומרת אם לשיר גבוה או נמוך יותר.
הכול רץ בדפדפן, בלי שרת. הקול לא נשלח לשום מקום.

הרצה: `python3 -m http.server 8000` ואז לפתוח `http://localhost:8000`
(המיקרופון עובד על localhost או על HTTPS בלבד).

## בדיקות

`npm test` (דורש Node 18+, בלי תלויות). הבדיקות מסנתזות שמע (אקורדים עם הרמוניות, בס, תופים, שירה עם ויברטו),
ומריצות עליו את אותו קוד של האפליקציה: FFT, זיהוי גובה צליל, זיהוי ומעקב סולם.
בדיקות "ביקורת" מוכיחות שהבדיקות מסוגלות להיכשל (למשל: בלי סינון שירה, ועם סולם קפוא).
מגבלות ידועות מסומנות כ-`todo` ומופיעות בדוח.
